========================================================================
  SUFLER — srodowisko pracy z Claude Code            [ wersja polska ]
========================================================================

INSTALACJA (30 sekund)

  1. Przeciagnij ikone "Sufler" na katalog "Applications" (Programy)
     widoczny obok w tym oknie.

  2. Otworz Programy i uruchom Sufler.

  3. PRZY PIERWSZYM URUCHOMIENIU macOS zablokuje aplikacje i pokaze
     ostrzezenie — Sufler nie ma platnego podpisu Apple Developer ID.
     To normalne i wystarczy jednorazowo potwierdzic:

        a) Kliknij ikone Sufler prawym przyciskiem (albo Ctrl + klik)
           -> "Otworz" -> w okienku ostrzezenia jeszcze raz "Otworz".

        b) Jesli okienko nie daje przycisku "Otworz" (macOS Sequoia
           i nowsze): zamknij je, wejdz w Ustawienia systemowe ->
           "Prywatnosc i ochrona", przewin na dol do komunikatu
           o zablokowanym Suflerze i kliknij "Otworz mimo to".

     Robi sie to tylko raz. Kolejne uruchomienia sa juz zwyklym klikiem.

     Gdyby system dalej odmawial (komunikat "aplikacja jest uszkodzona"),
     wklej w Terminalu jedna linijke i nacisnij Enter:

        xattr -dr com.apple.quarantine /Applications/Sufler.app

KTORY PLIK DMG DLA MOJEGO MACA

     Sufler-<wersja>-arm64.dmg   Maki z procesorem Apple (M1, M2, M3, M4)
     Sufler-<wersja>-x64.dmg     Maki z procesorem Intel

     Sprawdzisz to w menu Apple -> "Ten Mac" (pozycja "Uklad" lub "Procesor").

CZEGO POTRZEBUJESZ

     - Claude Code (CLI) — karty "Claude" uruchamiaja polecenie `claude`.
       Instalacja: https://claude.com/claude-code
     - git — panel zmian, historia i wykres repozytorium.

     Terminale, edytor i drzewo plikow dzialaja takze bez tych narzedzi.

PIERWSZE KROKI

     Po starcie wybierz folder roboczy — ekran startowy pokazuje ostatnie
     projekty razem z ich ikonami. Terminale i sesje Claude startuja
     wlasnie w tym folderze.

     Ustawienia (motyw, kolor przewodni, jezyk PL/EN): Cmd + przecinek.

     Ustawienia aplikacji zapisuja sie w ~/.config/sufler/.
     Aplikacja pracuje lokalnie — nie wysyla nigdzie Twoich plikow.


========================================================================
  SUFLER — a workspace for Claude Code                [ English version ]
========================================================================

INSTALL (30 seconds)

  1. Drag the "Sufler" icon onto the "Applications" folder shown next
     to it in this window.

  2. Open Applications and launch Sufler.

  3. ON FIRST LAUNCH macOS blocks the app and shows a warning — Sufler
     is not signed with a paid Apple Developer ID certificate. This is
     expected and needs a one-time confirmation:

        a) Right-click (or Ctrl + click) the Sufler icon -> "Open"
           -> click "Open" again in the warning dialog.

        b) If the dialog has no "Open" button (macOS Sequoia and newer):
           dismiss it, go to System Settings -> "Privacy & Security",
           scroll to the bottom where Sufler is listed as blocked and
           click "Open Anyway".

     Only needed once; later launches are a normal double click.

     If macOS still refuses ("the application is damaged"), paste this
     single line into Terminal and press Enter:

        xattr -dr com.apple.quarantine /Applications/Sufler.app

WHICH DMG DO I NEED

     Sufler-<version>-arm64.dmg   Macs with Apple silicon (M1-M4)
     Sufler-<version>-x64.dmg     Macs with an Intel processor

     Apple menu -> "About This Mac" tells you which one you have.

REQUIREMENTS

     - Claude Code (CLI) — the "Claude" tabs run the `claude` command.
       Install: https://claude.com/claude-code
     - git — for the changes panel, history and commit graph.

     Terminals, the editor and the file tree work without them.

GETTING STARTED

     Pick a working folder on the welcome screen (recent projects are
     listed with their own icons). Terminals and Claude sessions start
     in that folder.

     Settings (theme, accent colour, PL/EN language): Cmd + comma.

     App settings live in ~/.config/sufler/. Everything runs locally —
     your files are never uploaded anywhere.
